# ClipPacks

A collection of reusable, ready-to-import AI agent teams and organization templates for Paperclip.

ClipPacks keeps each organization as a portable pack under `packs/`. Its first pack is the [Paperclip ACON team](packs/paperclip-acon-team/README.md), a reusable 17-agent roster with standalone instructions and its own package-specific support and license documents.

## Repository layout

```text
packs/paperclip-acon-team/  First importable organization package
  .paperclip.yaml           Package manifest
  COMPANY.md                Organization and roster data
  agents/<role>/AGENTS.md   17 standalone role instructions
  README.md, TEAM.md,
  VALIDATION.md, LICENSE.md  Pack-specific guidance and notices
docs/                       Installation and general maintainer/user guides
```

The pack files are kept at the archive root: when distributing a pack ZIP, include `.paperclip.yaml`, `COMPANY.md`, `agents/`, and the four support documents directly, not an extra enclosing repository directory.

## Compatibility and safety

The first pack records the captured Paperclip master source pin `fd057f6ac4e9148bb4055883ae1d0e7f49242692` and schema 7. A comparison with Paperclip `v2026.1012.0` is not a full compatibility audit or certification for any installed release. Check the pack's [validation record](packs/paperclip-acon-team/VALIDATION.md) and target instance before importing.

A ZIP does not pause imported agents. Follow the new-organization UI flow and explicitly request `pauseAutomations: true`; then verify resulting statuses, ownership, membership, and effective permissions before activation. Heartbeat settings and reporting prompts are not an ACL, permission boundary, or proof of workspace/session isolation. This repository records no live import or runtime validation.

## Releases

For installation, download the pack-specific named ZIP from this repository's GitHub **Releases → Assets**. Do not download GitHub's autogenerated **Source code (zip)** as an import package. See the [installation guide](docs/installation.md) and [maintainer guide](docs/guide.md).
